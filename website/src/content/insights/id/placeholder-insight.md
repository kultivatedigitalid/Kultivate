# Pentingnya Mengukur Core Web Vitals

Kecepatan halaman bukan lagi sekadar opsi estetika. Google secara eksplisit menggunakan Core Web Vitals (LCP, FID/INP, CLS) sebagai sinyal pengalaman pengguna dan pemeringkat SEO. Prospek bisnis seringkali meninggalkan halaman jika pemuatan memerlukan waktu lebih dari 3 detik.
